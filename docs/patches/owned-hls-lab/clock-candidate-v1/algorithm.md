# Native observation clock candidate v1 — frozen before held-out capture

Scope: offline source-position estimator only. No production, Kodi Core, device, or capture-waveform calibration changes. Training dataset is capture-first; next capture is held out. This file and estimator.py are hashed before any candidate/capture comparison.

At each native clock_sample, query time is mach_absolute_ns plus the midpoint of the steady-clock GetDelay bracket minus steady_ns. Raw source position is accepted_adddata_frames / 48000 minus audioengine_delay_s. The absolute anchor is the trailing nine raw positions minus elapsed host time; take their median. No waveform, fitted intercept, source matching, or control-RPC timestamp is an estimator input.

Constants fixed from the 20 ms polling cadence and 1024/48000 s AAC period: nine observations; minimum acquisition span 120 ms; maximum inter-query gap 100 ms; maximum query width 5 ms; median absolute deviation no greater than half an AAC period (10.6666667 ms). An innovation exceeding two AAC periods (42.6666667 ms) against the prior median invalidates the anchor and restarts acquisition. Smaller outliers remain in the median window. A stable accepted endpoint and host anchor produce min(endpoint, host+anchor), monotonically clamped to the previous output within an epoch. A backward correction greater than one sample is uncertain until the unclamped estimate catches up.

Startup, failure, missing/invalid observations, counter/epoch resets, and acquisition are uncertain. Pause retains the last stable anchor, continues its predicted tail toward the last accepted endpoint, then holds that endpoint. The entire pause/tail interval is uncertain: this predicts a source tail, not confirmed physical audibility. Resume discards the old window/anchor and reacquires nine observations. An underrun that reaches the accepted endpoint is uncertain, holds that endpoint, and reacquires after accepted data increases. Drained is uncertain and must not be treated as an audible-end measurement. No valid output is produced outside play/resume. No extrapolation beyond the final ledger row is emitted.

Source basis: AudioEngine.h documents GetDelay as seconds until the next added packet is heard; GetCacheTime excludes engine buffers. ActiveAE.cpp CEngineStats::GetDelay adds sink latency, global buffered samples and per-stream/resampler buffers. AEUtil.cpp AEDelayStatus::GetDelay subtracts elapsed host time only up to maxcorrection, inherited from the original sink delay. Thus the aggregate delay can retain nonzero cached/latency components after that correction stops; cache zero, IsDrained, or the pause RPC is not proof of tail exhaustion. This estimator assumes unresampled 48 kHz unit-rate source playback and an epoch without source discontinuities; change of output device/rate or sustained delay bias requires invalidation not available from the current ledger.

Evaluation contract: score every original independently waveform-qualified report sample, retaining all 114 first-capture points. Report all-point errors, valid-point errors and invalid points separately; an invalid point is not a passing observation. The next capture must use this same code/hash and parameters. Capture process-tap timestamps validate that acquisition domain only, not physical speaker audibility. Median filtering cannot remove systematic latency/domain bias, and its observed dispersion is not a proven error bound.
