## Shared wire contract

Extend binding/hello/readiness with `output_backend`, `hal_contract_version=1`, pinned device UID/format and lifecycle capability proof. AE defaults remain explicit and compatible. New record kinds are `hal_segment`, `hal_query`, `hal_gain_ack`, `hal_terminal`; JSON integers/booleans are strict, duplicate/nonfinite values rejected, each native line remains at most 16384 bytes.

`HalSegment` carries session identity, sequence, device/stream/in-flight generations, playback revision/epoch, gain transport revision/effective epoch, source_start/count, requested/consumed/copied/zero_frames, applied gain/muted, timestamp flags/sample time, output/inNow/entry/exit host ticks and timebase. `HalQuery` carries native query bracket/q (checked integer midpoint), covering segment identity, mapped source frame, current/applicable generations, reasons and eligibility. `GainCommand` carries binding, sequential revision, request_start/end, issue/expiry, integer volume, muted and a diagnostic derived multiplier; native code always derives its authoritative gain from validated integer volume/muted and rejects inconsistent supplied values. `GainAck` adds first effective output boundary. Include original segment/query raw hashes in later audit; never hash reconstructed rows as originals.
